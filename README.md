# C Programming Exercises & Projects

A structured repository containing foundational C programming concepts, exercises, and mini-projects. This repo serves as a personal log of learning progress, covering everything from core syntax to functional applications.

---

## 📂 Repository Structure

The project is organized into logical directories based on topics:

*   **basics/**: Fundamental concepts including input/output, arithmetic operations, basic data types, and simple geometry calculations. *(Includes: area of a circle, square root, character ASCII shifting/typing, side validation, and basic summation)*
*   **conditions/**: Programs implementing decision-making logic using `if`, `else if`, and `else` statements. *(Includes: digit validation, pass/fail status, leap years, factors, and even/odd parity checks)*
*   **loops/**: Examples demonstrating iterative logic using `for`, `while`, and `do-while` loops. *(Includes: math tables, counting sequences, character printing, power exponents, and nested loop geometric pattern designs)*
*   **functions/**: Modular code examples showcasing pass-by-value, math operations, and utility functions. *(Includes: prime number checks, value swapping, factorials, maximum number checks, and modular table functions)*
*   **arrays/**: Programs focused on continuous memory allocation, array traversal, searching, and manipulation. *(Includes: input/mark storage, single and corresponding element summation, inversion algorithms, and conditional filtering)*
*   **mini_projects/**: Small, practical console applications combining multiple concepts. *(Includes: temperature scales, real-time seconds calculators, operational grocery billing, and corporate salary computations)*
